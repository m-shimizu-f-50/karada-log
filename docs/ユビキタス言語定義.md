# ユビキタス言語定義

ドメイン用語・ビジネス用語・UI用語を定義し、会話・ドキュメント・コードで一貫した言葉を使う。

---

## 1. ドメイン用語

### 記録（Record）

ユーザーが特定の日付に入力したデータの1件。体重・食事・運動それぞれに存在する。

| 用語     | 英語           | 説明                                           |
| -------- | -------------- | ---------------------------------------------- |
| 体重記録 | WeightRecord   | 特定日の体重（kg）の記録1件                    |
| 食事記録 | MealRecord     | 特定日・食事区分における食品1件の記録          |
| 運動記録 | ExerciseRecord | 特定日に行った運動1件の記録                    |
| 目標体重 | WeightGoal     | ユーザーが設定する目標体重（kg）。1ユーザー1件 |

### カロリー（Calorie）

| 用語         | 英語           | 説明                                                                 |
| ------------ | -------------- | -------------------------------------------------------------------- |
| 摂取カロリー | CaloriesIntake | 1日の食事記録から合計した摂取カロリー（kcal）                        |
| 消費カロリー | CaloriesBurned | 1日の運動記録から合計した消費カロリー（kcal）                        |
| カロリー収支 | CalorieBalance | 摂取カロリー − 消費カロリー の差分。正の値は余剰、負の値は不足を示す |

### 食事区分（MealType）

食事記録における時間帯の区分。

| 用語 | 英語（コード値） | 説明                   |
| ---- | ---------------- | ---------------------- |
| 朝食 | `breakfast`      | 朝の食事               |
| 昼食 | `lunch`          | 昼の食事               |
| 夕食 | `dinner`         | 夜の食事               |
| 間食 | `snack`          | 食事以外の時間帯の飲食 |

| 用語           | 英語            | 説明                                                 |
| -------------- | --------------- | ---------------------------------------------------- |
| ユーザー       | User            | Googleアカウントでログインしたサービス利用者         |
| ログイン       | SignIn          | Googleアカウントで認証し、サービスを利用開始すること |
| ログアウト     | SignOut         | 認証セッションを終了すること                         |
| ダッシュボード | Dashboard       | 今日の記録サマリーを一覧表示するトップ画面           |
| 推移グラフ     | ProgressChart   | 体重の時系列変化を可視化した折れ線グラフ             |
| LINE連携       | LineIntegration | LINEからメッセージを送るだけで記録が作成される機能   |

## 4. 英語・日本語対応表（コード命名基準）

コードで変数・関数・コンポーネント名を付ける際はこの表の英語を使用する。

### エンティティ

| 日本語       | コードで使う英語 | 例                                 |
| ------------ | ---------------- | ---------------------------------- |
| ユーザー     | user             | `userId`, `currentUser`            |
| 体重記録     | weightRecord     | `weightRecord`, `WeightRecord`     |
| 目標体重     | weightGoal       | `weightGoal`, `WeightGoal`         |
| 食事記録     | mealRecord       | `mealRecord`, `MealRecord`         |
| 運動記録     | exerciseRecord   | `exerciseRecord`, `ExerciseRecord` |
| 食事区分     | mealType         | `mealType: MealType`               |
| 体重         | weight           | `weight: number`                   |
| カロリー     | calories         | `calories: number`                 |
| 摂取カロリー | caloriesIntake   | `caloriesIntake`                   |
| 消費カロリー | caloriesBurned   | `caloriesBurned`                   |
| カロリー収支 | calorieBalance   | `calorieBalance`                   |
| 運動種目     | exerciseName     | `exerciseName: string`             |
| 運動時間     | durationMinutes  | `durationMinutes: number`          |
| 目標体重     | targetWeight     | `targetWeight: number`             |
| 記録日       | date             | `date: Date`                       |

### 操作・関数

| 日本語   | コードで使う英語 | 例                                  |
| -------- | ---------------- | ----------------------------------- |
| 取得する | get / fetch      | `getWeightRecords()`, `fetchMeal()` |
| 作成する | create           | `createWeightRecord()`              |
| 更新する | update           | `updateWeightGoal()`                |
| 削除する | delete           | `deleteMealRecord()`                |
| 計算する | calculate        | `calculateCalorieBalance()`         |
| 解析する | parse            | `parseLineMessage()`                |
| 送信する | send             | `sendLineMessage()`                 |
| 検証する | validate         | `validateWeight()`                  |

### 画面・コンポーネント

| 日本語         | コードで使う英語 | 例                               |
| -------------- | ---------------- | -------------------------------- |
| ダッシュボード | Dashboard        | `DashboardPage`, `WeightSummary` |
| 体重記録       | Weight           | `WeightForm`, `WeightChart`      |
| 食事記録       | Meal             | `MealForm`, `MealList`           |
| 運動記録       | Exercise         | `ExerciseForm`, `ExerciseList`   |
| カロリー収支   | CalorieBalance   | `CalorieSummary`                 |
| ヘッダー       | Header           | `Header`                         |
| ナビゲーション | Nav              | `BottomNav`                      |

## 5. 使用しない言葉（揺れを防ぐ）

同じ概念に複数の表現が生まれないよう、使用する言葉を統一する。

| 使用しない表現   | 統一する表現   | 理由                               |
| ---------------- | -------------- | ---------------------------------- |
| 体重ログ         | 体重記録       | 「記録」に統一                     |
| 食ログ・食事ログ | 食事記録       | 「記録」に統一                     |
| トレーニング     | 運動           | サービスの対象が軽い運動も含むため |
| カロリーバランス | カロリー収支   | より直感的な表現                   |
| サインイン       | ログイン       | UIの表示ラベルに合わせる           |
| ホーム           | ダッシュボード | 機能を示す名称に統一               |
