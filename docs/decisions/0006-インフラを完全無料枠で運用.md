# ADR-0006: インフラを完全無料枠で運用する

- 日付: 2026-05-10
- 状態: 承認済み

## 背景

個人開発・学習目的のアプリであるため、コストをゼロに抑えることが必須条件だった。
フロントエンド・バックエンド・データベースそれぞれのデプロイ先を選定した。

## 決定

以下の構成で完全無料運用する。

| 役割 | サービス | 無料枠の内容 |
|---|---|---|
| フロントエンド | **Vercel** | 個人利用は無制限・常時稼働 |
| バックエンド | **Render** | 月750時間・15分無操作でスリープ |
| データベース | **Supabase** | 500MB・2プロジェクト |

## 各サービスの選定理由

### Vercel（フロントエンド）

- Next.js の開発元が提供するデプロイサービスで相性が最良
- 個人利用は実質無制限で常時稼働
- PR 作成時にプレビュー URL が自動生成され、デプロイ確認が簡単

### Render（バックエンド）

- Node.js サーバーを無料でデプロイできる数少ないサービス
- Prisma が使えるため、バックエンド技術選定（Hono + Prisma）と相性が良い
- **スリープあり**（15分無操作で停止、次のリクエストで再起動）という制限があるが、個人利用・学習用途では許容範囲

### Cloudflare Workers を選ばなかった理由

- Cloudflare Workers は常時稼働・無料枠が豊富だが、Prisma が動作しない
- Prisma を採用する場合（ADR-0004）、Cloudflare Workers は選択できない
- Drizzle ORM に変更すれば使えるが、実務採用率を考慮して Prisma を優先した

## トレードオフ・注意点

- Render のスリープ仕様により、15分以上操作がなかった後の最初のリクエストで起動に数十秒かかる
- 本番運用（有料化）を検討する場合は Render の有料プランまたは Railway への移行を検討する
- Supabase の無料プロジェクトは一定期間非アクティブだと一時停止される
