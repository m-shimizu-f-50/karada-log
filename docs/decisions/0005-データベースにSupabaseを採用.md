# ADR-0005: データベースに Supabase（PostgreSQL）を採用

- 日付: 2026-05-10
- 状態: 承認済み

## 背景

アプリのデータを永続化するためのデータベースサービスの選定が必要だった。
無料枠での運用を必須条件とした。

## 検討した選択肢

| 選択肢 | 無料枠 | 特徴 |
|---|---|---|
| **Supabase** | 500MB・2プロジェクト | PostgreSQL。管理 UI が充実 |
| Neon | 0.5GB | サーバーレス PostgreSQL。Cloudflare Workers と相性が良い |
| PlanetScale | 無料枠終了 | MySQL ベース |
| Railway | $5/月クレジット | 完全無料ではない |

## 決定

**Supabase（PostgreSQL）** を採用する。

## 理由

- 無料枠（500MB）が個人利用・学習用途には十分
- PostgreSQL を採用しているため、標準的な SQL スキルが身につく
- 管理コンソール（Supabase Studio）が充実しており、テーブル・データの確認・編集が GUI でできる
- Prisma との組み合わせ実績が豊富でドキュメント・事例が多い
- 実務でも採用事例が増えており、学習価値が高い

## トレードオフ・注意点

- 無料プロジェクトは一定期間（1週間）アクティビティがないと一時停止される場合がある
- 無料枠の上限（500MB）を超えると課金が発生するため、データ量に注意が必要
- Supabase の独自機能（Realtime・Auth・Storage）は今回使用せず、PostgreSQL の接続先としてのみ使用する
