## 3. `backend/` ディレクトリ

Hono（Node.js）によるバックエンド API サーバー。
データの取得・保存・削除を担当し、Prisma 経由で Supabase（PostgreSQL）に接続する。

```
backend/
├── prisma/
│   ├── schema.prisma                   # スキーマ定義
│   └── migrations/                     # マイグレーションファイル
├── src/
│   ├── index.ts                        # エントリーポイント（Hono アプリ起動）
│   ├── routes/
│   │   ├── weight.ts                   # /api/weight, /api/weight/:id, /api/weight/goal
│   │   ├── meal.ts                     # /api/meal, /api/meal/:id
│   │   └── exercise.ts                 # /api/exercise, /api/exercise/:id
│   ├── middleware/
│   │   └── auth.ts                     # JWT 検証ミドルウェア
│   └── lib/
│       ├── db.ts                       # Prisma Client のシングルトン
│       └── validations.ts              # Zod バリデーションスキーマ
├── .env                                # ローカル環境変数（Git 管理対象外）
├── .env.example                        # 環境変数テンプレート（Git 管理対象）
├── tsconfig.json
├── eslint.config.mjs
└── package.json
```

## 4. `middleware.ts`（フロントエンド）

`frontend/` 直下に配置する。
未ログインユーザーが保護ページにアクセスした際にログインページへリダイレクトする。

```ts
// 保護対象のパス（matcher で指定）
/dashboard, /weight, /meal, /exercise

// 未認証 → /（ログインページ）へリダイレクト
// 認証済み → そのままアクセスを許可
```

## 5. テストファイルの配置ルール

テストファイルはテスト対象ファイルと同じディレクトリに配置する。

```
backend/src/lib/
├── validations.ts
└── validations.test.ts     # ← 同じディレクトリに配置
```

| 対象 | テストの優先度 |
|---|---|
| `backend/src/lib/validations.ts` | 高（純粋関数・バリデーションロジック） |
| `backend/src/middleware/` | 中（認証ロジック） |
| `backend/src/routes/` | 中（API の正常系・異常系） |
| `frontend/src/components/` | 低（UIは目視確認を優先） |

## 6. ファイル命名規則

| 種別 | 規則 | 例 |
|---|---|---|
| React コンポーネント | PascalCase | `WeightForm.tsx` |
| ページ（App Router） | `page.tsx` 固定 | `app/weight/page.tsx` |
| Hono ルートファイル | camelCase | `weight.ts` |
| Hooks | camelCase・`use` プレフィックス | `useWeight.ts` |
| ユーティリティ・lib | camelCase | `api-client.ts` |
| 型定義 | camelCase | `weight.ts` |
| テスト | `[対象ファイル名].test.ts(x)` | `validations.test.ts` |

## 7. 環境変数ファイル

| ファイル | Git 管理 | 用途 |
|---|---|---|
| `frontend/.env.local` | 対象外 | フロントエンド用ローカル環境変数 |
| `frontend/.env.example` | 対象 | フロントエンド環境変数テンプレート |
| `backend/.env` | 対象外 | バックエンド用ローカル環境変数 |
| `backend/.env.example` | 対象 | バックエンド環境変数テンプレート |

### `frontend/.env.example`

```bash
# NextAuth.js
NEXTAUTH_URL=http://localhost:3000
AUTH_SECRET=your-auth-secret

# Google OAuth
AUTH_GOOGLE_ID=your-google-client-id
AUTH_GOOGLE_SECRET=your-google-client-secret

# バックエンド API
NEXT_PUBLIC_API_URL=http://localhost:8080
```

### `backend/.env.example`

```bash
# Supabase（PostgreSQL）
DATABASE_URL=postgresql://user:password@host:5432/dbname

# JWT 検証（フロントエンドの AUTH_SECRET と同じ値）
AUTH_SECRET=your-auth-secret

# サーバー
PORT=8080
```
