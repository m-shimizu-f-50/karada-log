## セクション 1: フロントエンド初期化

### 実施したこと

- `create-next-app` で `/tmp` に作成し、既存ファイルと衝突しないよう `frontend/` にコピーする形でセットアップ
- `layout.tsx` / `page.tsx` / `globals.css` のデフォルトコードを削除してクリーンな状態にした
- `public/` のデフォルト SVG（next.svg / vercel.svg など）を削除
- `next-auth@beta` / `zod` / `react-hook-form` / `recharts` / `vitest` をインストール
- `package.json` に `type-check`（`tsc --noEmit`）と `test`（`vitest`）スクリプトを追加
- Atomic Design に沿ったフォルダ構造（`atoms/` `molecules/` `organisms/` `templates/`）を作成
- `.env.example` と `.gitignore` を作成

### ポイント・気づき

- `layout.tsx` はすべてのページに共通で適用される HTML の外枠。`<html>` と `<body>` タグはここだけに書く
- `globals.css` は `@import "tailwindcss"` の1行だけで Tailwind CSS が有効になる
- Git は空フォルダを管理できないため、`.gitkeep` という空ファイルを置いてフォルダ構造を確保する
- `.env.local` は `.gitignore` に含める必須ファイル。コミットすると API キーが漏洩する
- `tsc --noEmit` は TypeScript のコンパイルをせず、型チェックだけ行うコマンド

### 確認したこと

- `npm run dev` で `http://localhost:3000` が HTTP 200 で返ることを確認
