## セクション 4: 認証（NextAuth.js）

> **学習テーマ**: OAuth フロー・JWT によるフロント・バック間の認証連携を理解する

- [ ] 4-1. Google Cloud Console で OAuth 2.0 クライアントを作成する
  - 承認済みリダイレクト URI: `http://localhost:3000/api/auth/callback/google`
- [ ] 4-2. `frontend/.env.local` に以下を設定する
  - `AUTH_SECRET`（`npx auth secret` で生成）
  - `AUTH_GOOGLE_ID`
  - `AUTH_GOOGLE_SECRET`
  - `NEXT_PUBLIC_API_URL=http://localhost:8080`
- [ ] 4-3. `backend/.env` に `AUTH_SECRET` を設定する（フロントエンドと同じ値）
- [ ] 4-4. `frontend/src/lib/auth.ts` に NextAuth.js の設定を記述する
  - Google Provider
  - JWT コールバックでユーザー ID をトークンに含める
- [ ] 4-5. `frontend/src/app/api/auth/[...nextauth]/route.ts` にハンドラを配置する
- [ ] 4-6. `frontend/middleware.ts` を作成してログイン必須ルートを保護する
  - 保護対象: `/dashboard`・`/weight`・`/meal`・`/exercise`
- [ ] 4-7. `frontend/src/lib/api-client.ts` を作成する
  - セッションから JWT を取得し、Authorization ヘッダーに付けて fetch する関数を定義する
- [ ] 4-8. `backend/src/middleware/auth.ts` に JWT 検証ミドルウェアを実装する
  - `AUTH_SECRET` を使って JWT を検証する
  - 検証成功時にユーザー ID を `c.set('userId', ...)` で後続の処理に渡す
- [ ] 4-9. `frontend/src/app/page.tsx` にログインページを実装する
  - 「Google でログイン」ボタン
  - デザインシステムに沿ったスタイリング
- [ ] 4-10. Google アカウントでログイン・ログアウトできることを確認する
- [ ] 4-11. 未ログイン状態で `/dashboard` にアクセスするとリダイレクトされることを確認する
