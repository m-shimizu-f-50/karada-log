## 読み方

各ファイルは以下の構成になっています。

1. **このセクションで作るもの** — 完成イメージ
2. **前提知識** — このセクションを理解するために必要な概念
3. **実施内容** — 何をどの順番でやったか
4. **ファイルごとの解説** — 各ファイルのコードを1行ずつ説明
5. **全体のつながり** — ファイル間の関係図
6. **ハマった点・補足** — つまずいた箇所とその解決策
