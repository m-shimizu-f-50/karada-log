---

## 前提知識

### Node.js とは

JavaScript をブラウザの外（サーバーやパソコン上）で動かすための実行環境。
`npm`（パッケージ管理ツール）も Node.js に含まれている。

### npm とは

Node.js のパッケージ（ライブラリ）を管理するツール。
`npm install パッケージ名` でライブラリをダウンロードして使えるようにする。

```bash
npm install react    # react をダウンロードして node_modules/ に保存
```

### Next.js とは

React をベースにしたウェブフレームワーク。
React だけでは「どのURLでどのページを表示するか」のルーティングなどを自分で設定する必要があるが、
Next.js を使うとファイルを置くだけでルーティングが自動設定されるなど、多くの設定が省略できる。

### TypeScript とは

JavaScript に「型」を追加した言語。
型とは「この変数は文字列だ」「この関数は数値を返す」という情報のこと。
型があることで、タイプミスや間違った使い方をコードを書いている段階で検出できる。

```typescript
// JavaScript: エラーが実行時まで分からない
let name = "太郎"
name = 123  // 実行するまで気づかない

// TypeScript: 書いた瞬間にエラーを検出
let name: string = "太郎"
name = 123  // ← ここでエラー「string 型に number は代入できない」
```

## 実施内容

### 1. Next.js プロジェクトを作成した

```bash
npx create-next-app@latest frontend --typescript --tailwind --eslint --app --src-dir --no-import-alias
```

各オプションの意味：
| オプション | 意味 |
|---|---|
| `frontend` | プロジェクト（フォルダ）の名前 |
| `--typescript` | TypeScript を使う |
| `--tailwind` | Tailwind CSS を使う |
| `--eslint` | ESLint（コード品質チェックツール）を使う |
| `--app` | App Router を使う（Next.js の新しいルーティング方式） |
| `--src-dir` | ソースコードを `src/` フォルダに入れる |

### 2. デフォルトのサンプルコードを削除した

`create-next-app` で作られるプロジェクトには Next.js のデモコードが含まれている。
それを全部消して、真っ白な状態から始めた。

削除・変更したもの：
- `src/app/page.tsx` → シンプルなプレースホルダーに書き換え
- `src/app/globals.css` → Tailwind の読み込み1行だけに削減
- `src/app/layout.tsx` → タイトルを `Karada Log` に変更
- `public/` → デフォルトの SVG ファイルを削除

### 3. 追加パッケージをインストールした

```bash
npm install next-auth@beta          # Google ログイン（セクション4で使用）
npm install zod                     # バリデーション（入力値のチェック）
npm install react-hook-form @hookform/resolvers  # フォーム管理
npm install recharts                # グラフ描画（体重グラフで使用）
npm install -D vitest @vitejs/plugin-react  # テストツール
```

### 4. フォルダ構造を作成した

空フォルダは Git で管理できないため、`.gitkeep` という空ファイルを置いて確保した。

```
src/
├── components/
│   ├── atoms/       ← 最小単位のUI部品（ボタン・入力欄など）
│   ├── molecules/   ← atoms を組み合わせた部品
│   ├── organisms/   ← 機能を持つ複合部品（フォーム全体など）
│   └── templates/   ← ページ全体のレイアウト
├── lib/             ← ユーティリティ関数・設定ファイル
├── hooks/           ← カスタムフック（状態管理ロジック）
└── types/           ← TypeScript の型定義
```

## 作成されたファイルの解説

### `src/app/layout.tsx` — すべてのページの外枠

```tsx
import type { Metadata } from "next";
import "./globals.css";

// ブラウザのタブに表示されるタイトルと説明
export const metadata: Metadata = {
  title: "Karada Log",
  description: "体重・食事・運動を記録するアプリ",
};

// すべてのページに共通する HTML の外枠
export default function RootLayout({ children }) {
  return (
    <html lang="ja" className="h-full">
      <body className="min-h-full">
        {children}  {/* ← ここに各ページの内容が入る */}
      </body>
    </html>
  );
}
```

`layout.tsx` は **すべてのページに共通して適用される**。
`<html>` と `<body>` タグはここだけに書く。
`{children}` の部分に各ページ（`page.tsx`）の内容が差し込まれる。

### `src/app/globals.css` — グローバルスタイル

```css
@import "tailwindcss";
```

この1行だけで Tailwind CSS が使えるようになる。
Tailwind CSS は `className="text-white bg-gray-900 rounded-xl"` のように
クラス名を組み合わせてスタイルを書くライブラリ。

### `src/app/page.tsx` — トップページ（`/`）

```tsx
export default function Home() {
  return (
    <div className="flex min-h-screen items-center justify-center bg-gray-950">
      <p className="text-white text-2xl font-bold">Karada Log</p>
    </div>
  );
}
```

App Router では、`app/` フォルダ内の `page.tsx` がそのパスのページになる。
- `app/page.tsx` → `/`
- `app/dashboard/page.tsx` → `/dashboard`
- `app/weight/page.tsx` → `/weight`

### `package.json` — プロジェクトの設定ファイル

```json
{
  "scripts": {
    "dev": "next dev",          // 開発サーバー起動
    "build": "next build",      // 本番用ビルド
    "start": "next start",      // 本番サーバー起動
    "lint": "next lint",        // コード品質チェック
    "type-check": "tsc --noEmit",  // 型エラーチェック（追加）
    "test": "vitest"            // テスト実行（追加）
  },
  "dependencies": { ... },      // 本番環境でも必要なパッケージ
  "devDependencies": { ... }    // 開発時だけ必要なパッケージ
}
```

`dependencies` と `devDependencies` の違い：
- `dependencies`: アプリの実行に必要（React、Next.js など）
- `devDependencies`: 開発中だけ必要（TypeScript、テストツールなど）

## ファイル間の関係

```
ブラウザが http://localhost:3000 にアクセス
        ↓
Next.js が app/layout.tsx を読み込む（共通の外枠）
        ↓
app/page.tsx の内容を layout.tsx の {children} に差し込む
        ↓
globals.css のスタイルが適用される
        ↓
「Karada Log」と表示されたページが返る
```

---

## ハマった点・補足

- **App Router と Pages Router の違い**: Next.js には旧来の `pages/` ディレクトリを使う「Pages Router」と、新しい `app/` ディレクトリを使う「App Router」がある。このプロジェクトは新しい App Router を採用している
- **Git が空フォルダを管理できない**: Git はファイルを管理するツールのため、ファイルが1つもないフォルダはコミットできない。そのため `.gitkeep` という名前の空ファイルを置いて「このフォルダは存在する」ことを記録した
