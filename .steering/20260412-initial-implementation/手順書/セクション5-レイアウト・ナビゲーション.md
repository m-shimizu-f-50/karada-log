# セクション5: レイアウト・ナビゲーション

## このセクションで作るもの

ログイン後のすべてのページに共通する「外枠」を作る。

```
┌──────────────────────────────────┐
│ Karada Log          [ログアウト] │  ← Header（上部固定）
├──────────────────────────────────┤
│                                  │
│     ページごとのコンテンツ        │  ← children（各ページ）
│                                  │
├──────────────────────────────────┤
│  🏠ホーム  ⚖️体重  🍽食事  🏋運動 │  ← BottomNav（下部固定）
└──────────────────────────────────┘
```

---

## 前提知識

### Server Component と Client Component の違い

Next.js App Router では、コンポーネントは「サーバーで動く」か「ブラウザで動く」かで2種類に分かれる。

| | Server Component | Client Component |
|---|---|---|
| **デフォルト** | ✅ デフォルト | ❌ `'use client'` を書く必要がある |
| **実行場所** | サーバー（Node.js） | ブラウザ |
| **DB / 秘密情報** | ✅ 直接アクセスできる | ❌ できない |
| **useState / useEffect** | ❌ 使えない | ✅ 使える |
| **onClick などのイベント** | ❌ 使えない | ✅ 使える |
| **usePathname / useRouter** | ❌ 使えない | ✅ 使える |

**使い分けの判断フロー**
```
クリックなどのイベントが必要？
  → YES → Client Component（'use client'）
  → NO  →
      useState / useEffect が必要？
        → YES → Client Component
        → NO  →
            usePathname / useRouter が必要？
              → YES → Client Component
              → NO  → Server Component（デフォルト）
```

このセクションでは：
- `Header.tsx` → ログアウトボタンの `onClick` が必要 → **Client Component**
- `BottomNav.tsx` → `usePathname` で現在のパスを取得する必要がある → **Client Component**
- `(authenticated)/layout.tsx` → ただ配置するだけ → **Server Component**

### Next.js のネストされたレイアウト

App Router では `layout.tsx` をネストできる。

```
app/
├── layout.tsx             ← ルートレイアウト（すべてのページに適用）
├── page.tsx               ← / （ログインページ）
└── (authenticated)/
    ├── layout.tsx         ← 認証済みページだけに適用されるレイアウト
    ├── dashboard/page.tsx ← /dashboard
    ├── weight/page.tsx    ← /weight
    └── ...
```

`/dashboard` にアクセスすると：
1. `app/layout.tsx` が適用される（html / body タグ）
2. `app/(authenticated)/layout.tsx` が適用される（Header / BottomNav）
3. `app/(authenticated)/dashboard/page.tsx` が表示される

### ルートグループ `(authenticated)` とは

`(かっこ)` で囲ったフォルダは **URL に影響しない**。
フォルダを作ってファイルを整理するだけで、パスには含まれない。

```
app/(authenticated)/dashboard/page.tsx
              ↑
         URL には含まれない
→ アクセスするURLは /dashboard（/authenticated/dashboard ではない）
```

用途: ページのグループにだけレイアウトを適用したいとき。
今回は「ログイン済みのページにだけ Header と BottomNav を表示する」ために使っている。

### `sticky` と `fixed` の違い（CSS）

ヘッダーやナビゲーションバーを「常に画面上に固定する」ときに使う。

| | `sticky` | `fixed` |
|---|---|---|
| **基準** | 親要素の中 | 画面（ビューポート）全体 |
| **スクロール** | 親要素の範囲内でスクロールに追従 | 常に画面の同じ位置に固定 |
| **レイアウト** | スペースを占有する | スペースを占有しない |

Header → `sticky top-0`（上部に張り付く）
BottomNav → `fixed bottom-0`（画面下部に常に固定）

BottomNav が `fixed` なので「スペースを占有しない」= コンテンツが BottomNav の下に隠れてしまう。
そのため `main` に `pb-20`（下部パディング）を付けてコンテンツが隠れないようにしている。

## 作成されたファイルの解説

### `src/app/layout.tsx` — グローバルレイアウト（更新）

すべてのページに共通する外枠。背景グローエフェクトを追加した。

```tsx
export default function RootLayout({ children }) {
  return (
    <html lang="ja" className="h-full">
      <body className="min-h-full bg-gray-950">

        {/* 背景グローエフェクト */}
        <div className="fixed inset-0 -z-10 bg-gray-950">
          {/*
            fixed      = 画面全体に固定
            inset-0    = 上下左右すべて 0（画面全体を覆う）
            -z-10      = z-index: -10（すべてのコンテンツの後ろに置く）
          */}

          <div className="absolute top-0 left-1/4 w-96 h-96 bg-blue-500/10 rounded-full blur-3xl" />
          {/*
            absolute   = 親要素（fixed の div）を基準に配置
            top-0      = 上端
            left-1/4   = 左から25%の位置
            w-96 h-96  = 幅・高さ 384px の円
            bg-blue-500/10 = 青色の10%透明度
            rounded-full   = 完全な円形
            blur-3xl       = 強いぼかし（光彩のような効果）
          */}

          <div className="absolute top-1/3 left-1/2 w-96 h-96 bg-purple-500/10 rounded-full blur-3xl" />
          <div className="absolute bottom-0 right-1/4 w-96 h-96 bg-pink-500/10 rounded-full blur-3xl" />
        </div>

        {children}
      </body>
    </html>
  )
}
```

**なぜ `fixed inset-0 -z-10` なのか？**
- `fixed` = スクロールしても動かない
- `inset-0` = 画面全体を覆う（`top:0, right:0, bottom:0, left:0` のショートハンド）
- `-z-10` = すべてのコンテンツより後ろに置く（コンテンツが隠れないように）

### `src/components/organisms/Header.tsx` — ヘッダー（Client Component）

```tsx
'use client'
// ↑ このファイルはブラウザで動く Client Component

import { signOut } from 'next-auth/react'
// ↑ next-auth/react から signOut をインポート
//   Client Component では next-auth/react を使う
//   Server Component では @/lib/auth から signOut を使う（使い分けに注意）

export default function Header() {
  return (
    <header className="sticky top-0 z-10 bg-gray-900/80 backdrop-blur-md border-b border-gray-800">
    {/*
      sticky top-0    = スクロールしても上部に張り付く
      z-10            = 他のコンテンツより手前に表示
      bg-gray-900/80  = gray-900 色の80%透明度
      backdrop-blur-md = 背景をぼかす（すりガラス効果）
      border-b        = 下部のボーダー
    */}
      <div className="flex items-center justify-between px-4 h-14">
      {/*
        flex                 = フレックスボックス（横並び）
        items-center         = 縦方向に中央揃え
        justify-between      = 左右に分散配置（タイトルは左、ボタンは右）
        h-14                 = 高さ 56px
      */}

        {/* グラデーションテキスト */}
        <span className="text-lg font-bold bg-gradient-to-r from-blue-400 via-purple-400 to-pink-400 bg-clip-text text-transparent">
          Karada Log
        </span>

        {/* ログアウトボタン */}
        <button
          onClick={() => signOut({ callbackUrl: '/' })}
          {/*
            signOut() を呼ぶとログアウト処理を実行する
            callbackUrl: '/' = ログアウト後にトップページ（ログインページ）に移動
          */}
          className="text-sm text-gray-400 hover:text-white transition-colors duration-200"
        >
          ログアウト
        </button>
      </div>
    </header>
  )
}
```

**`next-auth/react` と `@/lib/auth` の `signOut` の違い**

| インポート元 | 使える場所 | 仕組み |
|---|---|---|
| `next-auth/react` | Client Component | HTTP リクエストで `/api/auth/signout` を呼ぶ |
| `@/lib/auth` | Server Component / Server Action | サーバー側で直接実行する |

### `src/components/organisms/BottomNav.tsx` — ボトムナビゲーション（Client Component）

```tsx
'use client'

import Link from 'next/link'
import { usePathname } from 'next/navigation'
import { LayoutDashboard, Scale, Utensils, Dumbbell } from 'lucide-react'

// タブの定義（ここを変えればタブを追加・削除できる）
const navItems = [
  { href: '/dashboard', label: 'ホーム',  Icon: LayoutDashboard },
  { href: '/weight',    label: '体重',    Icon: Scale },
  { href: '/meal',      label: '食事',    Icon: Utensils },
  { href: '/exercise',  label: '運動',    Icon: Dumbbell },
]

export default function BottomNav() {
  const pathname = usePathname()
  // ↑ 現在のURL パス（例: '/dashboard', '/weight'）を取得する
  //   Client Component でしか使えない

  return (
    <nav className="fixed bottom-0 left-0 right-0 z-10 bg-gray-900/80 backdrop-blur-md border-t border-gray-800">
    {/*
      fixed bottom-0 left-0 right-0 = 画面下部に固定・横幅いっぱい
    */}
      <div className="flex">
        {navItems.map(({ href, label, Icon }) => {
          const isActive = pathname === href
          // ↑ 現在のパスとタブのパスが一致するとき「アクティブ」

          return (
            <Link
              key={href}
              href={href}
              className="flex flex-1 flex-col items-center gap-1 py-3"
            >
            {/*
              flex-1 = 各タブが均等に幅を分け合う（4タブなら各25%）
            */}
              {isActive ? (
                /* アクティブ時: グラデーションアイコン */
                <div className="relative">
                  <Icon size={22} className="text-transparent" />
                  <div className="absolute inset-0 flex items-center justify-center">
                    <Icon size={22} style={{ stroke: 'url(#nav-gradient)' }} />
                  </div>
                  {/* SVG グラデーション定義 */}
                  <svg width="0" height="0" className="absolute">
                    <defs>
                      <linearGradient id="nav-gradient" x1="0%" y1="0%" x2="100%" y2="0%">
                        <stop offset="0%"   stopColor="#60a5fa" />  {/* blue-400 */}
                        <stop offset="50%"  stopColor="#a78bfa" />  {/* purple-400 */}
                        <stop offset="100%" stopColor="#f472b6" />  {/* pink-400 */}
                      </linearGradient>
                    </defs>
                  </svg>
                </div>
              ) : (
                /* 非アクティブ時: グレーアイコン */
                <Icon size={22} className="text-gray-500" />
              )}

              {/* ラベル（アクティブ時はグラデーション文字） */}
              <span className={isActive
                ? 'text-xs font-semibold bg-gradient-to-r from-blue-400 via-purple-400 to-pink-400 bg-clip-text text-transparent'
                : 'text-xs text-gray-500'
              }>
                {label}
              </span>
            </Link>
          )
        })}
      </div>
    </nav>
  )
}
```

**`usePathname()` とは？**
現在表示しているページの URL パスを返す React フック。
`/dashboard` にいれば `'/dashboard'`、`/weight` にいれば `'/weight'` が返る。
これを使ってどのタブがアクティブかを判断している。

**SVG グラデーションアイコンの仕組み**
Lucide React のアイコンは SVG で描かれており、色は `stroke`（線の色）で指定する。
グラデーションを stroke に適用するには SVG の `linearGradient` を定義する必要がある。
```html
<!-- グラデーション定義（画面に表示されない） -->
<defs>
  <linearGradient id="nav-gradient" ...>
    <stop offset="0%" stopColor="#60a5fa" />  ← 青
    <stop offset="100%" stopColor="#f472b6" /> ← ピンク
  </linearGradient>
</defs>

<!-- このグラデーションを使う -->
<Icon style={{ stroke: 'url(#nav-gradient)' }} />
```

### `src/app/(authenticated)/layout.tsx` — 認証済みページ共通レイアウト

```tsx
import Header from '@/components/organisms/Header'
import BottomNav from '@/components/organisms/BottomNav'

export default function AuthenticatedLayout({ children }) {
  return (
    <div className="flex flex-col min-h-screen">

      <Header />
      {/* ↑ ページ上部のヘッダー（sticky で固定） */}

      <main className="flex-1 pb-20">
        {children}
        {/*
          flex-1 = 残りのスペースをすべて占有する
          pb-20  = 下部パディング 80px
                   BottomNav が fixed で浮いているため、
                   コンテンツが BottomNav の下に隠れないようにする
        */}
      </main>

      <BottomNav />
      {/* ↑ ページ下部のナビゲーション（fixed で固定） */}

    </div>
  )
}
```

**このレイアウトが適用されるページ**
```
(authenticated)/
├── layout.tsx         ← このファイル
├── dashboard/page.tsx ← /dashboard
├── weight/page.tsx    ← /weight
├── meal/page.tsx      ← /meal
└── exercise/page.tsx  ← /exercise
```

`(authenticated)` フォルダ外の `app/page.tsx`（ログインページ）には適用されない。
→ ログインページには Header も BottomNav も表示されない（正しい動作）

## コンポーネント配置の考え方（Atomic Design）

このプロジェクトは Atomic Design という設計思想に従ってコンポーネントを分類している。

| 分類 | フォルダ | 内容 | 例 |
|---|---|---|---|
| **Atoms** | `components/atoms/` | 最小単位のUI部品 | ボタン・入力欄・ラベル |
| **Molecules** | `components/molecules/` | Atoms の組み合わせ | フォームフィールド（ラベル+入力欄）|
| **Organisms** | `components/organisms/` | 機能を持つ複合部品 | Header・BottomNav・体重フォーム |
| **Pages** | `app/**/page.tsx` | 実際のページ | ダッシュボード・体重記録ページ |

Header と BottomNav は「機能を持つ複合部品（organisms）」に分類している。
- 複数の要素（タイトル + ボタン、複数タブ）を組み合わせている
- 独立した機能（ログアウト、ページ遷移）を持っている

---

## ハマった点・補足

- **`next-auth/react` と `@/lib/auth` の使い分け**: Client Component での `signOut` は `next-auth/react` から。Server Component では `@/lib/auth` から。同じ名前の関数でもインポート元が違う
- **BottomNav の `fixed` による コンテンツ隠れ問題**: `fixed` 配置の要素はレイアウトのスペースを占有しないため、スクロールするとコンテンツが BottomNav の下に隠れる。`main` に `pb-20`（padding-bottom）を付けることで解決した
- **SVG グラデーションのアイコン**: Lucide React のアイコンの stroke にグラデーションを適用するには、SVG の `linearGradient` を定義して `url(#id)` で参照する方法を使った

## 確認したこと

- ログイン後に `/dashboard` でヘッダーとボトムナビが表示される
