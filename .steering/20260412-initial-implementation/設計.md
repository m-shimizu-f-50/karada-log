# 初回実装 設計書

## 実装方針

学習しながら理解を深めることを優先し、以下の原則で進める。

- **1セクション = 1学習単位**: 各セクションを完結させてから次へ進む
- **動く → 理解する → 次へ**: 実装後に動作確認し、コードの意味を確認する
- **小さく積み上げる**: 機能を一気に作らず、画面表示 → データ取得 → 保存 → 削除 の順に積み上げる
- **手順書に記録**: 各セクション完了後に `手順書.md` へ学びを記録する

---

## 技術構成

| 役割 | 技術 | デプロイ先 |
|---|---|---|
| フロントエンド | Next.js + NextAuth.js | Vercel（無料） |
| バックエンド | Hono + Node.js + Prisma | Render（無料・スリープあり） |
| データベース | PostgreSQL | Supabase（無料・500MB） |

## セクション別 実装アプローチ

---

### セクション 1: フロントエンド初期化

#### 学習ポイント

- `create-next-app` で生成されるファイル群の役割
- `app/` ディレクトリ（App Router）とページのルーティング
- `tsconfig.json` / `eslint.config.mjs` / `tailwind.config.ts` の基本設定
- `package.json` の依存関係管理

#### 実装アプローチ

1. `frontend/` ディレクトリに Next.js プロジェクトをセットアップ（作成済み）
2. デフォルトのサンプルコードをクリーンな状態にする
3. 必要なパッケージを追加インストール
4. リポジトリ構造定義書に従ってフォルダ構造を作成

#### インストールするパッケージ（フロントエンド）

```bash
# 認証
npm install next-auth@beta

# バリデーション
npm install zod

# フォーム
npm install react-hook-form @hookform/resolvers

# グラフ
npm install recharts

# テスト
npm install -D vitest @vitejs/plugin-react @testing-library/react
```

---

### セクション 2: バックエンド初期化

#### 学習ポイント

- Hono の基本的なルーティング（`app.get()` / `app.post()` など）
- Node.js での TypeScript 実行方法（`tsx` / `ts-node`）
- CORS 設定（フロントエンドからのリクエストを許可する）
- ポートのリッスンと `@hono/node-server` の使い方

#### 実装アプローチ

1. `backend/` ディレクトリに Hono + Node.js プロジェクトを作成
2. `src/index.ts` にエントリーポイントを作成（Hono アプリの起動）
3. CORS ミドルウェアを設定（`hono/cors`）
4. `/health` エンドポイントを作成して動作確認
5. `npm run dev` でローカルサーバーを起動し、`curl` / ブラウザで確認

#### インストールするパッケージ（バックエンド）

```bash
# Hono
npm install hono @hono/node-server

# ORM
npm install prisma @prisma/client

# バリデーション
npm install zod

# 開発ツール
npm install -D typescript @types/node tsx nodemon
```

---

### セクション 3: DB設計・Prisma セットアップ

#### 学習ポイント

- Prisma スキーマ（`schema.prisma`）でのモデル定義
- マイグレーションとは（スキーマの変更をDBに反映する仕組み）
- Prisma Client の使い方（`prisma.user.findMany()` など）
- Supabase の接続文字列の取得方法

#### 実装アプローチ

1. Supabase でプロジェクトを作成し、接続文字列を取得
2. `backend/.env` に `DATABASE_URL` を設定
3. `prisma/schema.prisma` に5テーブルのモデルを定義
4. `npx prisma migrate dev --name init` でマイグレーション実行
5. `npx prisma studio` でテーブル確認
6. `backend/src/lib/db.ts` に Prisma Client のシングルトンを作成

---

### セクション 4: 認証（NextAuth.js）

#### 学習ポイント

- OAuth 2.0 の認証フロー（認可コード → アクセストークン → ユーザー情報取得）
- NextAuth.js v5（Auth.js）のセットアップ方法
- JWT トークンをバックエンドに送る仕組み（Authorization ヘッダー）
- `middleware.ts` で未認証ユーザーをリダイレクトする仕組み
- バックエンド側での JWT 検証方法

#### 実装アプローチ

1. Google Cloud Console で OAuth 2.0 クライアントを作成
2. `frontend/src/lib/auth.ts` に NextAuth.js の設定を記述
3. `frontend/src/app/api/auth/[...nextauth]/route.ts` にハンドラを配置
4. `frontend/middleware.ts` で保護ルートを設定
5. `frontend/src/lib/api-client.ts` を作成（JWT を Authorization ヘッダーに付けて fetch）
6. `backend/src/middleware/auth.ts` に JWT 検証ミドルウェアを実装
7. ログインページを実装して Google ログイン動作確認

---

### セクション 5: レイアウト・ナビゲーション

#### 学習ポイント

- Server Component と Client Component の違いと使い分け
  - `onClick` などのイベントが必要 → Client Component（`"use client"`）
  - データ取得・認証確認 → Server Component
- Tailwind CSS でのダークテーマ・グラデーション実装

#### 実装アプローチ

1. `frontend/src/app/layout.tsx` にグローバルレイアウト・背景エフェクトを実装
2. `Header.tsx` を実装（タイトル + ログアウトボタン）
3. `BottomNav.tsx` を実装（アクティブタブをグラデーション強調）
4. `(authenticated)/layout.tsx` に共通レイアウトを作成

### セクション 6: 体重記録機能

#### 学習ポイント

- Hono でのルーティング定義とリクエスト/レスポンスの処理
- Prisma を使ったデータの取得・作成・削除（CRUD）
- フロントエンドから API を呼ぶ際の `api-client.ts` の使い方
- Recharts の `LineChart` / `ResponsiveContainer` の基本的な使い方

#### 実装アプローチ

**バックエンド**
1. `backend/src/routes/weight.ts` を作成
   - `GET /api/weight` — 直近30件取得
   - `POST /api/weight` — 登録（同日上書き）
   - `DELETE /api/weight/:id` — 削除（他ユーザーは403）
   - `GET /api/weight/goal` — 目標体重取得
   - `PUT /api/weight/goal` — 目標体重登録・更新
2. Zod バリデーションを追加

**フロントエンド**
3. `WeightForm.tsx` を実装
4. `WeightChart.tsx` を実装（Recharts）
5. `WeightHistory.tsx` を実装
6. `WeightGoalForm.tsx` を実装
7. `frontend/src/app/(authenticated)/weight/page.tsx` で組み合わせる
