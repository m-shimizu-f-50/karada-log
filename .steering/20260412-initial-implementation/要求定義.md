# 初回実装 要求定義

## 概要

Karada Log の初回実装。
認証・体重記録・食事記録・運動記録・カロリー収支表示の基本機能を実装する。
LINE連携はフェーズ2とし、本実装では対象外とする。

---

## 実装範囲

### 対象

| 機能 | 内容 |
|---|---|
| 環境セットアップ | Next.js プロジェクト作成・各種ライブラリ導入 |
| 認証 | Googleアカウントでのログイン・ログアウト |
| ダッシュボード | 今日の体重・カロリー収支のサマリー表示 |
| 体重記録 | 体重の登録・削除・推移グラフ・目標体重設定 |
| 食事記録 | 朝昼夜間食別の食事登録・削除・1日の摂取カロリー合計 |
| 運動記録 | 運動の登録・削除・1日の消費カロリー合計 |
| データベース | Prisma + Supabase（PostgreSQL）によるデータ永続化 |
| UI | ダークテーマ・ブルー→パープル→ピンクのグラデーションデザイン |

### 対象外（フェーズ2）

- LINE連携
- 写真による食事自動認識

---

## ユーザーストーリー

- ユーザーとして、Googleアカウントでログインしたい
- ユーザーとして、今日の体重・カロリー収支をダッシュボードで一目で確認したい
- ユーザーとして、毎日の体重を入力して推移グラフで確認したい
- ユーザーとして、目標体重を設定してグラフ上で現在との差を把握したい
- ユーザーとして、朝昼夜間食ごとに食事内容とカロリーを記録したい
- ユーザーとして、運動の種目・時間・消費カロリーを記録したい
- ユーザーとして、1日の摂取カロリーと消費カロリーの収支を確認したい

---

## 受け入れ条件

### 認証

- [ ] Googleアカウントでサインインできる
- [ ] サインアウトできる
- [ ] 未ログイン状態でダッシュボードにアクセスするとログインページへリダイレクトされる
- [ ] 自分のデータ以外にはアクセスできない

### ダッシュボード

- [ ] 今日の体重が表示される（未記録の場合は「未記録」と表示）
- [ ] 今日の摂取カロリー・消費カロリー・収支が表示される
- [ ] 各記録ページへのナビゲーションがある

### 体重記録

- [ ] 日付・体重（kg）を入力して保存できる
- [ ] 同日の記録は上書きされる
- [ ] 記録を削除できる
- [ ] 過去30日の推移が折れ線グラフで表示される
- [ ] 目標体重を設定・変更できる

### 食事記録

- [ ] 朝・昼・夜・間食のタブで切り替えられる
- [ ] 食品名・カロリーを入力して保存できる
- [ ] 記録を削除できる
- [ ] 1日の合計摂取カロリーが表示される

### 運動記録

- [ ] 運動種目・時間（分）・消費カロリーを入力して保存できる
- [ ] 記録を削除できる
- [ ] 1日の合計消費カロリーが表示される

### UI・非機能

- [ ] スマホブラウザ（iOS Safari / Android Chrome）で正常に動作する
- [ ] ダークテーマ・グラデーションデザインが適用されている
- [ ] Lint・型チェック・ビルドがすべてパスする

---

## 制約事項

- インフラはすべて無料枠で運用する（Supabase / Vercel）
- Redisは初回実装では使用しない（LINE連携実装時に導入）
- 認証はNextAuth.js v5（Auth.js）を使用する
